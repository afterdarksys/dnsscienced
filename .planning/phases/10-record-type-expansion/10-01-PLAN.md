<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| YAML zone file -> parser | Untrusted operator-authored YAML content parsed into DNS RRs |
| format string -> dns.NewRR() | Constructed string passed to miekg/dns for wire encoding |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-01 | Tampering | parseSSHFPRecords | mitigate | dns.NewRR() validates algorithm/fingerprint_type range and hex fingerprint format; invalid input returns error propagated to caller |
| T-10-02 | Tampering | parseNAPTRRecords | mitigate | dns.NewRR() validates NAPTR field encoding; Regexp quoting handled by miekg tokenizer; Replacement wrapped in dns.Fqdn() |
| T-10-03 | Tampering | parseSMIMEARecords | mitigate | dns.NewRR() rejects non-hex certificate data; same validation as TLSA path |
| T-10-04 | Tampering | parseLOCRecords | mitigate | dns.NewRR() validates LOC coordinate/altitude/precision encoding; malformed strings return error, not panic |
| T-10-05 | Denial of Service | parseNAPTRRecords | accept | NAPTR regexp string bounded by DNS message size limits in miekg; zone files are operator-controlled (not external input) |
| T-10-06 | Information Disclosure | all parse functions | accept | Zone file content is operator-authored configuration; no secrets in record data |
</threat_model>
