**Step A — Create internal/firewalld/edns0.go**

File content (copy verbatim — this is the complete reference implementation from RESEARCH.md):

```go
package firewalld

import (
	"github.com/miekg/dns"
	"github.com/rs/zerolog"
)

// edns0CustomerIDCode is the private-use EDNS0 option code carrying the
// customer identifier. RFC 6891 §6.1.3.1 reserves codes 65000–65534 for
// private use / local experimentation.
// Note: dns.EDNS0LOCALSTART = 0xFDE9 (65001); this code is 0xFDE8 (65000).
const edns0CustomerIDCode uint16 = 65000

// edns0MaxCustomerIDLen is the maximum accepted payload size in bytes.
// Chosen to accommodate UUID-prefixed variants (36 bytes for a bare UUID,
// headroom for short prefixes).
const edns0MaxCustomerIDLen = 64

// extractCustomerID returns the customer identifier from the EDNS0 option with
// code 65000, or "" if the option is absent or invalid.
// An oversized payload (> 64 bytes) is dropped with a single debug-level log.
func extractCustomerID(r *dns.Msg, logger zerolog.Logger) string {
	opt := r.IsEdns0()
	if opt == nil {
		return ""
	}
	for _, option := range opt.Option {
		local, ok := option.(*dns.EDNS0_LOCAL)
		if !ok || local.Code != edns0CustomerIDCode {
			continue
		}
		if len(local.Data) > edns0MaxCustomerIDLen {
			logger.Debug().
				Int("len", len(local.Data)).
				Msg("edns0 customer_id payload too large, ignoring")
			return ""
		}
		return string(local.Data)
	}
	return ""
}
```

CRITICAL — do NOT use `dns.EDNS0LOCALSTART` (65001) as the code value or comparator. Always compare `local.Code != edns0CustomerIDCode` (our literal 65000).

```go
func makeQueryWithCustomerID(name string, qtype uint16, customerID string) *dns.Msg {
	m := makeQuery(name, qtype)
	opt := new(dns.OPT)
	opt.Hdr.Name = "."
	opt.Hdr.Rrtype = dns.TypeOPT
	opt.Option = append(opt.Option, &dns.EDNS0_LOCAL{
		Code: edns0CustomerIDCode,
		Data: []byte(customerID),
	})
	m.Extra = append(m.Extra, opt)
	return m
}
```

```go
func TestExtractCustomerID(t *testing.T) {
	logger := zerolog.Nop()
	tests := []struct {
		name       string
		msg        *dns.Msg
		wantResult string
	}{
		{
			name:       "present",
			msg:        makeQueryWithCustomerID("example.com.", dns.TypeA, "cust-abc"),
			wantResult: "cust-abc",
		},
		{
			name:       "no_opt",
			msg:        makeQuery("example.com.", dns.TypeA),
			wantResult: "",
		},
		{
			name: "wrong_code",

				m := makeQuery("example.com.", dns.TypeA)
				opt := new(dns.OPT)
				opt.Hdr.Name = "."

				opt.Option = append(opt.Option, &dns.EDNS0_LOCAL{
					Code: 65001, // dns.EDNS0LOCALSTART — not our code

				})
				m.Extra = append(m.Extra, opt)

		})

}
```

| Boundary | Description |
|----------|-------------|
| DNS client → Firewall.Check() | Untrusted EDNS0 option payload crosses here — attacker controls option code, payload bytes, and payload length |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Denial of Service | extractCustomerID() — payload length check | mitigate | 64-byte hard cap (D-06): `if len(local.Data) > edns0MaxCustomerIDLen` drops oversized payload and emits exactly one debug-level log. Prevents memory amplification and log flooding. Constant `edns0MaxCustomerIDLen = 64` makes the cap grep-verifiable. |
| T-04-02 | Tampering | extractCustomerID() — UTF-8 conversion | accept | `string(local.Data)` passes raw bytes through without validation (D-05). Malformed UTF-8 produces replacement characters; downstream string matching (Starlark, ThreatIntel) simply fails to match any known customer — no crash, no injection vector. Go spec guarantees no error on invalid UTF-8 conversion. |
| T-04-03 | Spoofing | extractCustomerID() — option code check | mitigate | Exact-code check `local.Code != edns0CustomerIDCode` (literal 65000) in the loop. Wrong code (e.g., 65001 from a vendor extension) silently continues — no early exit, no false match. |
| T-04-04 | Elevation of Privilege | Firewall.Check() — CustomerID trust bonus | accept | CustomerID is operator-controlled via EDNS0 — unauthenticated. The ThreatIntel trust bonus is a scoring modifier, not an access control gate. Operators who rely on unauthenticated EDNS0 for elevated trust accept this risk. Noted in RESEARCH.md security domain; enforcement is out of scope for this phase (CUST-04 is a v2 requirement). |
