```go
// KeyReloader allows hot-swapping API keys without restarting the server.
// Obtain via the fourth return value of New().
type KeyReloader struct {
    keySet *atomicKeySet
}

// Reload atomically replaces the API key set.
// Safe to call from any goroutine (e.g., a SIGHUP handler).
// If keys is empty AND mTLS is not configured, no reload occurs (would violate fail-closed policy).

    r.keySet.Store(keys)
}
```

with a signal loop:
```go
sigCh := make(chan os.Signal, 1)
signal.Notify(sigCh, syscall.SIGINT, syscall.SIGTERM, syscall.SIGHUP)

var keyReloader *grpcserver.KeyReloader // assigned after New()

for sig := range sigCh {
    switch sig {
    case syscall.SIGHUP:
        if keyReloader == nil || *configFile == "" {
            fmt.Println("SIGHUP received but no config file path or key reloader available; ignoring")
            continue
        }
        reloaded, err := config.Load(*configFile)
        if err != nil {
            fmt.Fprintf(os.Stderr, "SIGHUP: failed to reload config: %v; keeping current keys\n", err)
            continue
        }
        keyReloader.Reload(reloaded.Admin.APIKeys)
        fmt.Printf("SIGHUP: admin API keys reloaded (%d keys)\n", len(reloaded.Admin.APIKeys))
    case syscall.SIGINT, syscall.SIGTERM:
        fmt.Println()
        goto shutdown
    }
}
shutdown:
```

|----------|-------------|
| SIGHUP → config file read → key set | Signal triggers privileged file read; config file permissions are the control |
| main.go → grpcserver.New() | All auth config flows through this call; misconfiguration is now fatal |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|

| T-07-05-02 | Denial of Service | SIGHUP with corrupt config causes empty key set | mitigate | config.Load() returns error on parse failure; Reload() not called on error — current keys retained |
