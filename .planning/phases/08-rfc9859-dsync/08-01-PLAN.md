<feature>
  <name>Per-source-IP NOTIFY rate limiter (internal/dsync/ratelimit.go)</name>
  <files>internal/dsync/ratelimit.go, internal/dsync/ratelimit_test.go</files>
  <behavior>
    RED tests first — write ratelimit_test.go, then implement ratelimit.go.

    Test cases (write these BEFORE implementation):
    - TestNotifyRateLimiter_Allows: NewNotifyLimiter(10, 5); first 5 Allow(ip) calls for same IP all return true (within burst).
    - TestNotifyRateLimiter_Blocks: NewNotifyLimiter(0.001, 1) (nearly zero rate); call Allow(ip) twice immediately; second call returns false.
    - TestRateLimiterEviction: Create limiter with lastSeen tracking; manually set a visitor's lastSeen to 11 minutes ago; call sweepStale(); visitor should be gone from map.
    - TestRateLimiterDifferentIPs: Two different IPs each get independent limiters; one exhausted does not affect the other.

    Implementation (implement AFTER tests are RED):

    type visitor struct {
        limiter  *rate.Limiter
        lastSeen time.Time
    }

    type NotifyLimiter struct {
        mu       sync.Mutex
        visitors map[string]*visitor
        r        rate.Limit
        b        int
    }

    func NewNotifyLimiter(rps float64, burst int) *NotifyLimiter:
      - Initialize visitors map, r = rate.Limit(rps), b = burst.
      - Start a background goroutine (via go nl.cleanupLoop()) that calls nl.sweepStale() every 5 minutes.

    func (nl *NotifyLimiter) Allow(ip net.IP) bool:
      - key := ip.String()
      - Lock mu; get or create visitor (rate.NewLimiter(nl.r, nl.b)); update lastSeen = time.Now(); unlock.
      - Return lim.Allow().

    func (nl *NotifyLimiter) sweepStale():
      - Lock mu; delete visitors where time.Since(v.lastSeen) > 10 minutes; unlock.

    func (nl *NotifyLimiter) cleanupLoop():
      - ticker := time.NewTicker(5 * time.Minute); defer ticker.Stop()
      - for range ticker.C { nl.sweepStale() }

    Note: cleanupLoop runs forever (no stop channel needed for this phase; goroutine is tied to process lifetime). The test for eviction calls sweepStale() directly.
  </behavior>
</feature>
