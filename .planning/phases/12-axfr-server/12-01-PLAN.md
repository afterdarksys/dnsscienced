Create `internal/server/axfr.go` with the `handleAXFR` method on `*Server`. Package: `server`.

Imports: `"net"`, `"sync"`, `"github.com/miekg/dns"`.

The handler implements this guard chain (each failure returns immediately with the specified rcode):

1. **UDP truncation (D-08):** If `w.RemoteAddr()` is `*net.UDPAddr`, set `m.Truncated = true` on the reply and return. No answer section, no REFUSED — TC=1 signals RFC-compliant clients to retry over TCP.

2. **TSIG presence check (D-04):** If `r.IsTsig() == nil` (no TSIG record at all), return NOTAUTH (`dns.RcodeNotAuth`, value 9). This check MUST come before the validity check — an absent TSIG produces `TsigStatus() == nil`, so checking validity first silently accepts unsigned requests.

3. **TSIG validity check (D-05):** If `w.TsigStatus() != nil` (TSIG present but verification failed — bad key, bad sig, replay), return NOTAUTH.

4. **Empty question guard:** If `len(r.Question) == 0`, return REFUSED.

5. **Zone lookup:** `qname := r.Question[0].Name`, look up `z, ok := s.cfg.Zones[qname]`. If not found, return REFUSED.

6. **ACL check (D-01, D-03):** `acl := s.zoneTransferACLs[qname]`. If `acl == nil` (no allow_transfer configured — D-01 secure-by-default) OR `!acl.Check(clientIP)` (source not in allowlist — D-03), return REFUSED.

7. **Multi-message streaming (D-09):** Use `dns.Transfer.Out()` with channel-driven envelopes:

```go
const axfrBatchSize = 100

ch := make(chan *dns.Envelope)
tr := new(dns.Transfer)
var wg sync.WaitGroup
wg.Add(1)
go func() {
    tr.Out(w, r, ch) //nolint:errcheck
    wg.Done()
}()

// Opening SOA (RFC 5936 §2.2)
ch <- &dns.Envelope{RR: []dns.RR{z.SOA}}

// Middle: all zone RRs — GetAllRecords iterates z.Records only, does NOT include z.SOA
rrs := z.GetAllRecords()
for i := 0; i < len(rrs); i += axfrBatchSize {
    end := i + axfrBatchSize
    if end > len(rrs) {
        end = len(rrs)
    }
    ch <- &dns.Envelope{RR: rrs[i:end]}
}

// Closing SOA (RFC 5936 §2.2)
ch <- &dns.Envelope{RR: []dns.RR{z.SOA}}
close(ch)
wg.Wait()
w.Close() //nolint:errcheck
```

For every error response (REFUSED, NOTAUTH), use the same pattern:
```go
m := new(dns.Msg)
m.SetReply(r)
m.Rcode = dns.RcodeXxx
w.WriteMsg(m) //nolint:errcheck
return
```

Do NOT use `pool.GetMessage()` in this file — AXFR exits before pool acquisition (D-07).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| TCP client → handleAXFR | Untrusted secondary DNS server sends AXFR request; must be authenticated (TSIG) and authorized (ACL) |
| UDP client → handleAXFR | Untrusted client sends AXFR over wrong transport; must get TC=1 redirect, not zone data |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-01 | Spoofing | handleAXFR TSIG check | mitigate | Check `r.IsTsig() == nil` BEFORE `w.TsigStatus()` — absent TSIG rejected with NOTAUTH (D-04) |
| T-12-02 | Information Disclosure | handleAXFR zone content | mitigate | Per-zone allow_transfer ACL via dsync.SourceACL; empty list = REFUSED (D-01) |
| T-12-03 | Information Disclosure | handleAXFR unauthorized IP | mitigate | ACL check returns REFUSED before any zone data is streamed (D-03) |
| T-12-04 | Spoofing | TSIG replay | accept | miekg/dns TsigVerify checks timestamp fudge (300s default); auto-mitigated by library |
| T-12-05 | Denial of Service | AXFR flood | accept | AXFR exits early on ACL/TSIG failure before streaming; existing RRL covers query rate; zone transfer is inherently expensive but gated behind auth |
| T-12-06 | Tampering | AXFR response integrity | mitigate | Transfer.Out signs each outgoing message with TSIG automatically when request had TSIG |
| T-12-07 | Information Disclosure | Zone enumeration via UDP | mitigate | UDP AXFR returns TC=1 only — no zone data leaked on UDP (D-08) |
</threat_model>
