1. Add `currentZone := "."` after `iterations := 0` (line ~264).

2. Before the `r.queryNameserver` call, compute minimized name:
```go
// Compute minimized send name and type for this hop (D-02, D-03).
sendName := qname
sendType := qtype
if r.cfg.QNAMEMinimization {
    sendName = engine.ApplyQNAMEMinimization(qname, currentZone)
    // RFC 9156: intermediate hops use qtype=A; final hop uses original qtype.
    if sendName != qname {
        sendType = dns.TypeA
    }
}
```

3. Change the `r.queryNameserver` call to use `sendName, sendType` instead of `qname, qtype`:
```go
resp, err := r.queryNameserver(ctx, nameservers[0], sendName, sendType, qclass)
```

4. After the error-handling block (after the `continue` for next nameserver), add NODATA handling for intermediate minimized hops. Insert BEFORE the `if len(resp.Answer) > 0` check:
```go
// QNAME minimization NODATA at intermediate hop (RFC 9156 section 4):
// if minimized and answer is empty + NOERROR + no NS records, disable
// minimization and re-issue full qname to this same nameserver.
if r.cfg.QNAMEMinimization && sendName != qname &&
    len(resp.Answer) == 0 && resp.Rcode == dns.RcodeSuccess && len(resp.Ns) == 0 {
    resp, err = r.queryNameserver(ctx, nameservers[0], qname, qtype, qclass)
    if err != nil {
        if len(nameservers) > 1 {
            nameservers = nameservers[1:]
            continue
        }
        return nil, fmt.Errorf("all nameservers failed: %w", err)
    }
}
```

5. In the referral block (where `nameservers = newNameservers`), add currentZone update just before `continue`:
```go
// Update zone to delegation zone: use NS RR owner name (the zone),
// NOT ns.Ns (the nameserver hostname). Pitfall 5: must be FQDN.
currentZone = dns.Fqdn(strings.ToLower(resp.Ns[0].Header().Name))
```

Important: use `resp.Ns[0].Header().Name` (the zone being delegated), NOT `resp.Ns[0].(*dns.NS).Ns` (the nameserver hostname). This is a critical distinction per RESEARCH.md anti-patterns.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-05 | Information Disclosure | QNAME minimization | mitigate | RFC 9156 qtype=A at intermediate hops prevents leaking original qtype to non-authoritative nameservers |
| T-11-06 | Denial of Service | QNAME min NODATA loop | mitigate | NODATA at intermediate hop disables minimization and re-queries full QNAME once; MaxIterations bound prevents infinite loops |
| T-11-07 | Tampering | currentZone from referral | accept | NS authority owner name is from the same response that provided the referral; attacker would need to compromise the entire referral (which DNSSEC validation catches when enabled) |
