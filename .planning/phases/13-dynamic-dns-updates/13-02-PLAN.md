**handleUpdate method** — `func (s *Server) handleUpdate(w dns.ResponseWriter, r *dns.Msg, clientIP net.IP)` with this guard chain (per D-18, mirroring axfr.go):

1. TSIG presence: `r.IsTsig() == nil` → NOTAUTH (per D-16). MUST be before validity check.
2. TSIG validity: `w.TsigStatus() != nil` → NOTAUTH (per D-16).
3. Empty Zone section: `len(r.Question) == 0` → FORMERR.
4. Zone lookup: `zoneName := r.Question[0].Name; z, ok := s.cfg.Zones[zoneName]` → REFUSED if !ok.
5. ACL check: `acl := s.zoneUpdateACLs[zoneName]; if acl == nil || !acl.Check(clientIP)` → REFUSED (per D-15, D-17).
6. Lock `z.updateMu.Lock(); defer z.updateMu.Unlock()` (per D-06 — lock on LIVE zone, not clone).
7. Evaluate prerequisites: call `evaluatePrereqs(r.Answer, z)`. On failure, return the error rcode with zero updates (per D-03).
8. Clone: `clone := z.Clone()`.
9. Apply Update section (`r.Ns`) to clone — iterate each RR:
   - **Skip SOA records** in Update section (per D-10): `if rr.Header().Rrtype == dns.TypeSOA { continue }`.
   - **Add** (`rr.Header().Class == z.Class`): call `clone.AddRecord(rr)`. But first check CNAME coexistence: if adding CNAME and owner has non-CNAME records (or vice versa), return REFUSED (per D-04).
   - **Delete all rrsets at name** (`ClassANY, TypeANY`): if owner equals zone origin (case-insensitive), return REFUSED per D-04 (would delete SOA/NS). Otherwise call `clone.DeleteName(owner)`.
   - **Delete rrset** (`ClassANY, specific type`): if type is SOA, return REFUSED per D-04. If type is NS and owner equals zone origin, check that this would not remove ALL NS records — if `len(clone.GetRecords(owner, dns.TypeNS)) == 0` after delete, return REFUSED. Call `clone.DeleteRRSet(owner, rrtype)`.
   - **Delete specific RR** (`ClassNONE, specific type`): if type is SOA, return REFUSED per D-04. Call `clone.DeleteRecord(rr)`.
10. Validate clone: `clone.Validate()` → SERVFAIL on error (per D-05).
11. Increment serial: `clone.IncrementSerial()` (per D-09).
12. Atomic swap: `s.cfg.Zones[zoneName] = clone` (per D-05, DYNUP-04).
13. Reply NOERROR.

Use a local `sendRcode` helper to avoid repetitive reply construction.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| DNS client → handleUpdate | Untrusted UPDATE messages cross network boundary; must authenticate and authorize before any mutation |
| handleUpdate → zone.Zone | Mutations only on clones; live zone only swapped after full validation |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-04 | Spoofing | handleUpdate TSIG check | mitigate | Two-step TSIG guard: r.IsTsig()==nil THEN w.TsigStatus()!=nil (D-16); reversing order silently accepts unsigned requests |
| T-13-05 | Tampering | Unauthorized zone modification | mitigate | TSIG always required (D-16) + IP ACL via dsync.SourceACL (D-15/D-17); empty allow_update = nil ACL = deny all |
| T-13-06 | Tampering | SOA/NS deletion attack | mitigate | D-04: explicit checks reject delete-SOA, delete-all-NS at apex, CNAME coexistence violations; REFUSED before apply |
| T-13-07 | Tampering | Zone corruption via malformed UPDATE | mitigate | clone.Validate() after all mutations; swap only on success; original zone untouched on failure (D-05) |
| T-13-08 | Tampering | Race condition — concurrent zone mutations | mitigate | Per-zone updateMu serializes all UPDATE processing for same zone (D-06); lock before prereqs, unlock after swap |
| T-13-09 | Elevation of Privilege | IP ACL bypass via empty allow_update | mitigate | Empty CIDR list stored as nil in zoneUpdateACLs (never passed to NewSourceACL which would return allowAll=true); nil = deny all |
| T-13-10 | Spoofing | TSIG replay attack | mitigate | miekg/dns TsigStatus() validates time window + fudge per RFC 2845; no hand-rolled HMAC |
| T-13-11 | Denial of Service | Zone exhaustion via infinite adds | accept | Bounded by DNS message size (64KB UDP, larger TCP); no server-side limit needed for v1.3; existing RRL covers query path |
</threat_model>
