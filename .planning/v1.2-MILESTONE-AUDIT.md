## Executive Summary

Phases 6, 7, and 8 are individually verified as passing their own plan must-haves. However, cross-phase integration audit reveals **4 production wiring gaps** — subsystems built in Phase 6 that were deferred to Phase 7 for wiring, but Phase 7 never completed that wiring. The admin API has 4 RPCs that are permanently non-functional in the production binary as a result.

Additionally, a TSIG concurrent access data race was identified that could cause undefined behavior under concurrent load.

## Tech Debt (Non-Blocking)

### Phase 7 — Admin Auth Hardening

1. **TSIG concurrent access race** (`internal/tsig/tsig.go`): `Add()`/`Remove()` mutate `kr.secrets` under `kr.mu`, but `miekg/dns` reads `dns.Server.TsigSecret` (same map) without any lock. Data race under concurrent `AddTsigKey` + TSIG DNS query. Fix: implement `dns.TsigProvider` interface on `KeyRing`, or copy-on-write map.

2. **Stream interceptor key ID lost** (`api/grpc/server/server.go`): `apiKeyStreamInterceptor` discards key ID (`_, ok := keySet.Lookup(token)`). `AuditStreamInterceptor` falls back to cert CN for caller field. Latent — no streaming admin RPCs currently. Fix: add `ctx = context.WithValue(ctx, middleware.CtxKeyID{}, id)` in stream interceptor.

3. **TSIG bootstrap blocked**: `tsigKeyRing` only initialized when `len(cfg.TsigKeys) > 0` (server.go:299). `AddTsigKey` returns `FailedPrecondition` if no keys in startup YAML. Fix: always initialize `tsigKeyRing`; zero-key ring is valid.

4. **ShutdownServer silently no-ops**: `shutdownFn` nil (register.go:77). Returns `{success: false}` with gRPC OK status. Fix: wire a shutdown callback from `main.go`, or change to `codes.Unimplemented`.

### Phase 6 — Admin API Stubs & Registration

5. **GetMetrics latency hardcoded to 0.0**: `AvgLatencyMs` and `P99LatencyMs` are intentionally 0.0 with TODO comments (service.go:899-900). Intentional deferral per Plan 04 — requires EMA/histogram tracking infrastructure.

### Phase 8 — RFC 9859 DSYNC

6. **SetWebhook per-zone wiring deferred**: WebhookClient infrastructure fully implemented + tested. Per-zone URL wiring requires zone iteration at server init — documented deferral in Plan 07 comment.

7. **scheduleDelegationCheck stub**: Logs only. No CDS/CSYNC delegation engine. RFC 9859 full compliance requires delegation maintenance — correctly out of Phase 8 scope per ROADMAP.
