## Milestone Summary

**Key Decisions:**
- AND-auth policy (cert + key): cert proves machine identity, API key proves operator intent — enforced even for mTLS connections
- NOTIFY opcode dispatched before pool/defensive: NOTIFY is control-plane traffic, must bypass query processing
- TypeDSYNC=66 defined in-package: miekg/dns does not define it; RFC3597 fallback used for zone file parsing
- Shared-map pattern for TSIG: KeyRing.secrets is the same map reference assigned to dns.Server.TsigSecret; mutations are visible on next request without restart
- ConnRegistry uses gRPC stats.Handler: UUID assigned per connection, key ID enriched by auth interceptor post-auth
- extractBearer() replaces fmt.Sscanf: Sscanf truncates tokens at spaces; custom parsing avoids silent truncation

**Issues Resolved:**
- AdminService registration gap: all admin RPCs returned Unimplemented at v1.1 close; fully fixed in Phase 6
- Auth bypass: empty API key list allowed all connections; removed in Phase 7
- TSIG zero-key ring: uninitialized keyRing caused nil dereference; fixed in Phase 9
- Stream interceptor key ID: key ID not propagated to stream context; fixed via keyIDStream wrapper
- ListZones missing fields: SourceFile, Compiled (.dzc), Serial from SOA all missing; fixed in Phase 6

**Technical Debt Incurred:**
- ListConnections returns real data but KillConnection returns success=false with API limitation message (transport-layer connection kill requires OS-level socket ops not yet implemented)
- DNSSEC signing of DSYNC zones (RECOMMENDED per RFC 9859) deferred — validator exists but no online signing
- ConnRegistry production wiring verified but UAT is manual (07-HUMAN-UAT.md)
